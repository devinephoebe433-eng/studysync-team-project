# StudySync Project Board Plan

The GitHub Project should be created with the title **StudySync Team Board** and linked to the `studysync-team-project` repository.

## Suggested columns

| Column | Purpose |
|---|---|
| Backlog | Ideas and work that have not been prioritized for the current milestone. |
| Ready | Issues with clear acceptance criteria that are ready to start. |
| In progress | Work currently assigned to a team member. |
| In review | Pull requests or implementation work waiting for teammate review. |
| Done | Work that meets its acceptance criteria and has been merged. |
