# StudySync

StudySync is a web application that helps college students organize assignments, deadlines, study sessions, and group projects in one place. It is designed for students who want to manage schoolwork more effectively and avoid missing important due dates.

## Local setup

```bash
npm install
npm run dev
```

Open http://localhost:3000. Validate the production build with `npm run build` and run linting with `npm run lint`.

## Workflow

`main` is the protected integration branch. Work should happen on feature branches and merge through pull requests with at least one teammate review. The repository uses strict TypeScript, the Next.js App Router, Tailwind CSS, and the committed `.prettierrc` file.
