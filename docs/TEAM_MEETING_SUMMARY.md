## Selected proposal

**Title:** StudySync

**Description:** StudySync is a web application that helps college students organize assignments, deadlines, study sessions, and group projects in one place. It is designed for students who want to manage schoolwork more effectively and avoid missing important due dates.

**Problem being addressed:** Students often track assignments, deadlines, and responsibilities across multiple classes and applications. StudySync provides one organized location for planning schoolwork and collaborating with classmates.

**Why the team selected it:** The proposal addresses a common student need, has a clear MVP, and gives the team meaningful practice with CRUD workflows, calendar views, dashboards, shared project spaces, and responsive full-stack development.

## Project setup decisions

The team repository uses Next.js with the App Router, TypeScript, and Tailwind CSS. The `main` branch is the protected integration branch. Team members work on feature branches and merge through pull requests that receive at least one teammate review. Prettier formatting is committed in `.prettierrc`, and the full specification is stored in `docs/SPECIFICATION.md`.
